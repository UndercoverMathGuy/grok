# L2 — light junk cannot pay

Fork report, 2026-09-25. Scope: chain step L2 of CHAIN.md ("Large p" breakdown). Single-frequency networks (every neuron's
three slots at one frequency), two operands (nu = 3), plain weight decay (q = 2), every odd prime p. Scripts in `L2/`.
Labels: PROVED (full proof here), CERTIFIED(float) (finite check whose logic is rigorous but run in fp64, not intervals),
NUMERICAL (evidence only), FALSE.

| R_k | a bound on \|Psi_l\| for the light frequency k: how much a light neuron's content can be *amplified* by the aim |

For single-frequency nets, every admissible aim and every D give (V3a.2-4, Vf.1, verified to 1e-15):

    margin <= (2/p^3) sum_k cov_k(D) Re sum_{l at k} c_l Psi_l .                                   (M)

## 1. The lemma

> **LEMMA L2 (PROVED).** Fix a single-frequency network, a cut eps in (0, 1), and an admissible aim (it may depend on the
> network and on D). Assume:
> - **(H) heavy side** — for every k in H there is y_k >= 0 with Re sum_l c_l Psi_l <= y_k for every D, and
>   cost_k >= 3^{1/3} y_k^{2/3}. (This is what the chain's heavy side delivers: eta-form 3b with an l2-ball aim of depth
>   >= 0.272 [y_k = (|G_k| - 0.272 eta_k)_+], or DA at depth 1/2 with product Riesz aims [y_k = (min_{|t|=1/2} Re h_k)_+].)
> - **(L) light side** — for every k in L and every atom l at k, |Psi_l| <= R_k; put R = max_{k in L} R_k.
>
> Then  score <= B · Phi(sigma),  Phi(sigma) = Gamma* (1 - sigma)^{3/2}/sqrt3 + R · Lambda_p(sigma, eps),
> where Lambda_p(sigma, eps) = eps^{3/2} S_m + (sigma - m eps)^{3/2} mu_{m+1}, m = floor(sigma/eps),
> mu_{i+1} = 1 + cos(pi(2i+1)/p) (all coverage values, sorted decreasingly), S_m = mu_1 + ... + mu_m.
> Also score <= B · (p/(p-1)) [ (1 - sigma)^{3/2}/sqrt3 + R sqrt(eps) sigma ].
> Hence score <= gamma_sym whenever, for the network's sigma, the smaller of the two brackets is <= Gamma*/sqrt3; and
> **score < gamma_sym for every network with sigma > 0 as soon as eps < Gamma*^2 / (12 R^2)** (clean corollary).

**Values of R (PROVED, §2c).**
- R = 1 if the aim has no Fourier mass at k's junk modes (then Psi = 1). Riesz aims have no mass there unless 2k is a
  signed sum of doubled heavy frequencies.
- R = (1 + tau)^2 for product aims whose slot moments at k's modes have modulus <= tau. A **Riesz aim** on a heavy set
  with distinct signed sums has tau <= 1/4 on every light frequency (the forced moment needs >= 2 factors of size <= 1/2),
  so **R = 25/16**.
- R = 4 for an arbitrary aim (|Psi| <= 4 pointwise). This is the case for the transfer-lemma aims of V3a.6, whose Fourier
  support is not controlled.

## 2. Proof

**(a) Reduction to shares.** Put (M) at an offset D. For k in H use (H). For k in L:
Re sum_l c_l Psi_l <= R sum_l |c_l| <= R (sum_l |c_l|^{2/3})^{3/2} = R cost_k^{3/2}
(the l1 norm is at most the l_{2/3} quasi-norm). So, with f_H(D) = sum_{k in H} cov_k(D) y_k,
margin <= (2/p^3) [ f_H(D) + R C^{3/2} sum_{k in L} cov_k(D) beta_k^{3/2} ]   for every D.

**(b) Option (i): test at the heavy argmin.** Let D0 minimise f_H. By the definition of Gamma*,
f_H(D0) <= Gamma* (sum_H y_k^{2/3})^{3/2} <= Gamma* (sum_H cost_k / 3^{1/3})^{3/2} = C^{3/2} Gamma* (1 - sigma)^{3/2}/sqrt3.
Light part: {cov_k(D0) : k in F} is a permutation of {1 - cos(2 pi j/p) : j = 1..h} (k -> +-k D0 mod p permutes F), i.e. of
{mu_1, ..., mu_h}. The map beta -> sum_L cov_k beta_k^{3/2} is convex, so its maximum over {0 <= beta_k <= eps, sum = sigma}
sits at a vertex: all shares 0 or eps except one. Pairing the largest shares with the largest coverage values
(rearrangement) gives <= Lambda_p(sigma, eps).
**Option (ii): average over all offsets.** avg_{D != 0} cov_k(D) = p/(p-1) for every k, and sum_H y_k <= (sum_H y_k^{2/3})^{3/2}.
So the average of the bracket is <= C^{3/2} (p/(p-1)) [(1 - sigma)^{3/2}/sqrt3 + R sqrt(eps) sigma], using beta^{3/2} <= sqrt(eps) beta.
A minimum over D is at most both. Then use budget (B): P_2 >= (6/p) C, so score = margin/P_2^{3/2} <= (2/p^3)(p/6)^{3/2} [...] = B [...].

**Clean corollary.** Lambda_p <= mu_1 sqrt(eps) sigma <= 2 sqrt(eps) sigma, and 1 - (1 - sigma)^{3/2} >= sigma on [0, 1]
(chord of a convex function). So option (i) <= Gamma*/sqrt3 - sigma (Gamma*/sqrt3 - 2R sqrt(eps)), which is < Gamma*/sqrt3
when sigma > 0 and eps < Gamma*^2/(12 R^2). This is strict, so rigidity (equality only junk-free) is preserved.

**(c) The factors.** For the plain pairing, row (a, b): atom l's contribution is Re c_l (1 + v_l1 U1)(1 + v_l2 U2)
(Vf.1: U = C + j1 + j2 + j12 = (2/p^3) sum cov Re h_k). The slot-1 flip gives (1 - v_l1 U1)(1 + v_l2 U2), and the slot-2 flip
the mirror. Averaging: Psi_l = 1 + v1 m1 + v2 m2 + v1 v2 m12 with m1 = E[s1 U1] and so on, each a moment of a probability,
so |m| <= 1 and |Psi| <= 4. Zero moments give Psi = 1. For product aims (rows a ~ rho1, b ~ rho2, flips mixed with a
common rho2), m12 = m1 m2 and Psi = (1 + v1 m1)(1 + v2 m2). For a Riesz slot density
rho(x) = p^{-1} prod_{i in H} (1 + 2 Re(lambda_i w^{2 k_i x})), |lambda_i| <= 1/2, its moment at mode 2k is a sum over
signed representations 2k = sum eps_i 2k_i of prod (lambda_i or conj); with distinct signed sums there is at most one.
Since k is not in +-H, it has >= 2 factors, so |m| <= 1/4. Flipping only changes signs. QED.

Large p (proven check, R = 1): c = 0.127 (p = 1009), 0.11 (p = 20011). It tends to ~0.10: at fixed eps and p -> infinity
the top 1/eps coverage values are all ~2, and option (i) degenerates to the clean bound except at small sigma.

**Gap: the proof is 2-2.6x below the truth at R = 1 (2.1x at p = 211) (1.6-1.8x at R = 4, ~2x at 25/16), and 4-6x below with the clean
formula.** The binding adversary (NUMERICAL) at the true threshold is *many light frequencies at the cap forming a
near-flat cover* (e.g. p = 59, R = 1: 17 light frequencies, 80% of the budget). Such a net is an equal-share ladder at
discount R sqrt3 and beats the block once R sqrt(eps) exceeds ~Gamma*/sqrt3, i.e. c ~ 1/(3R^2) (c_true ~ 0.35-0.47
observed). The proof loses because option (i) evaluates the light part at one offset (coverage up to 2), and option (ii)
evaluates the heavy part at the average (no Gamma* factor). Neither sees that a flat light cover and a peaked heavy
spectrum must be tested at the same offsets.
**Lever (NUMERICAL).** `L2/dual_cov.py`: spreading the test over the optimal heavy spectrum's binding offsets (5 at p = 59,
7 at p = 113) caps any light frequency's averaged coverage at 1.39 / 1.43 instead of 2. That would give ~2x in c near the
heavy optimum. Making it rigorous needs "near-optimal heavy spectra have rich binding sets", a stability statement about
the Gamma programme (at fixed p, checkable via the vertex formulation of astra ARGUMENT §2). Not done.

## 4. What this means for the chain (plain words)

- **Proved:** light frequencies (share < eps) can never lift a single-frequency network above the block, for every odd
  prime, if eps < Gamma*^2/(12 R^2). R measures how much the aim built for the heavy frequencies accidentally amplifies
  light neurons: R = 1 if the aim's spectrum misses the light modes, 25/16 for Riesz aims, 4 in general. Better constants
  (~2x) are certified at p = 59, 113, 211.
- **Consequence:** heavy sets have at most 1/eps = 12R^2/Gamma*^2 elements. With Gamma* >= c/sqrt(log p) (L0) that is
  O(R^2 log p). **But the constant is large**: with R = 1, 1/eps ~ 55-100 at p = 59-211, which exceeds h. At the paper's
  primes L2 does not shrink the heavy set at all; it only bites asymptotically.
- **Tension to flag for L3/L6:** the only small-R aims are Riesz products on distinct-sums sets, which forces
  |H| <~ log_3 p. L2's heavy set can be ~12 R^2 log p / c^2, far larger. So at large p the heavy aim will generally be a
  non-Riesz aim (R = 4, c = 1/192 clean), unless L3 builds heavy aims whose Fourier support provably avoids light junk
  modes. This is the real interface problem between L2 and L3.
- **Sanity** (`L2/endtoend.py`): actual p = 59 networks (optimal blocks plus light lone neurons at share <= eps_clean,
  random phases) never exceed gamma_sym (max 0.9999988).
