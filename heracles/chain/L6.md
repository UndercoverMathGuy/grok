# L6 — the middle regime, broken down and scanned (fork report, 2026-09-25)

Scope: n = 2 operands, q = 2, networks of single-frequency neurons (X is 3a.9's problem). Scripts in `chain/L6/`.
Labels: PROVED / CERTIFIED / NUMERICAL / FALSE.

## 0. Symbols (plain reading with each)

| symbol | meaning |
|---|---|
| T | a *heavy junky set*: frequencies that carry junk, each with budget share >= eps |
| eps | the share floor (from L1/L2: frequencies below eps are "light" and handled separately) |
| 2T | the doubled frequencies {2k mod p : k in T}; junk of frequency k sits at the character x -> w^{-2kx} |
| A*(T) | one-sided depth: the largest A such that one weighting of inputs can give every junk character of T an average of any phase and modulus <= A |
| A_s(T) | two-sided depth: the same with the weighting's negatives allowed too (what the flip lemma gives); A_s = 1/(Sidon constant of 2T) |
| a(T) | achievable aim depth in the l2 sense on all three junk patterns (the flip-enlarged body); c_lo(T) <= a(T) <= A_s(T) |
| c_lo(T) | the flip-enhanced transfer lower bound computed from (A*, A_s) (VERIFY.md "New lemma") |
| delta(a) | discount left at depth a: the extra clean amplitude per cost^{3/2} over the block. Lone-atom curve max(1, sqrt3 (1 - sqrt3 a)) (conjectural between 0 and 0.272; PROVED only as the step 1 for a >= 0.272, sqrt3 always) |
| delta_crit(T, eps) | the largest discount on T that the share-floored programme absorbs without beating Gamma* |
| d(T) | dissociated dimension: size of the largest subset of T whose 3^|S| signed sums of doubled frequencies are distinct |
| j(T) | shortest relation: fewest nonzero coefficients c_k in {-2,-1,1,2} with sum c_k (2k) = 0 mod p |
| E(T) | normalised additive energy of the symmetric set +-2T: E / |+-2T|^3 (small = Sidon-like, large = progression-like) |
| Gamma_T | the share programme restricted to shares supported on T |

**Requirement for all p** (VERIFY.md, L5 fork): for every heavy junky set T, delta(a(T)) <= delta_crit(T, eps).

## 1. The breakdown

L6 sits between two regimes:
- **L3 regime (almost dissociate => deep aim).** If d(T) = |T| (all signed sums distinct), Riesz products give
  A* = A_s >= 1/2, so a(T) >= c_lo >= transfer(1/2, 1/2) = 0.408 > 0.272, so delta = 1 and the requirement holds for every
  eps. PROVED (V3a.8a + the flip-transfer lemma; the constant 0.408 is from a sphere grid, NUMERICAL to 3 digits).
  Perturbative extension: a few extra elements reachable only by long relations (length j) cost O(2^{-j}) of depth.
- **L4 regime (structure => floor waste).** Structure raises delta_crit(T, eps) above 1: forcing every frequency of a
  structured T to carry share eps wastes budget at T's bad offsets (L5 numerics: progressions at p = 23, 59 have
  delta_crit ~1.12-1.38).
- **Gap.** Sets whose achievable depth a(T) < 0.244 (so some discount survives on the lone-atom curve) and
  delta(a(T)) > delta_crit(T, eps).

Sub-lemmas:
- **L6.1 depth from structure** (lower bound): a(T) >= F(d, j, E, |T|).
- **L6.2 floor waste from structure** (lower bound): delta_crit(T, eps) >= 1 + g(T, eps).
- **L6.3 matching**: delta(F) <= 1 + g for every T.
- **L6.4 the multi-offset lever** (section 2): replace the single depth a(T) by offset-dependent depths.

## 2. The multi-offset lever — PROVED (lemma), tested numerically in section 4

**Lemma (independent aims at +D and -D).** For a single-frequency net, an offset D, and any two input weightings w+
(used at offset D) and w- (used at -D), averaging the two gaps gives
margin <= (2/p^3) sum_k [ cov_k(D) Re G_k + Re < J_k , nu_k > ],  nu_k = (1/2)[(1 - w^{kD}) m+_k + (1 - w^{-kD}) m-_k],
where m+-_k in C^3 are the weightings' averages of frequency k's three junk characters. If the plain moment body contains
the l2-polyball of radius c, choose m+-_k of norm c with phases aligning each term against J_k:
Re <J_k, nu_k> = -c sqrt(2 cov_k(D)) |J_k|. Relative to the clean weight cov_k(D) this is depth c sqrt(2/cov_k(D)) >= c.
*Proof.* Each weighting gives the clean part Re[(1 - w^{+-kD}) G_k] (no row dependence), and these average to
cov_k(D) Re G_k. The scalar (1 - w^{+-kD}) multiplies all three junk patterns of frequency k alike, so the per-k phases can
be absorbed into the targets m+-_k. |1 - w^{kD}| = sqrt(2 cov_k(D)), and sqrt(2 cov) >= cov because cov <= 2. QED.
The flip lemma is the special case w- = (w+ shifted by D). The reachable set for the pair is the Minkowski sum
N_D = L+ M + L- M, which contains both the flip's set and the independent set.

**Assembly with offset-dependent depths — PROVED.** For each D: margin <= (2/p^3) sum_k cov_k(D) (|G_k| - a_k(D) eta_k) with
a_k(D) = max(a_flip, c sqrt(2/cov_k(D))). For each k, cost_k >= 3^{1/3} (|G_k| - a eta_k)^{2/3} holds for every a >= 0.272 (V3b),
and cost_k >= |G_k|^{2/3} always. So margin <= min_D sum_k cov_k(D) r_k(D) cost_k^{3/2}/sqrt3, with r_k(D) = 1 if
a_k(D) >= 0.272 and r_k(D) <= sqrt3 otherwise: an offset-dependent share programme. **Junk is fully priced at every offset
where the frequency covers poorly:** cov_k(D) <= 27.0 c^2 (from c sqrt(2/cov) >= 0.272).

## 3. Universal floors (any p, any T) — PROVED

- **Two-sided floor.** A_s(T) >= 1/sqrt(2K), K = |T|. Proof: for z != 0, f = Re sum z_k w^{-2kx} has
  sup|f| >= ||f||_2 = (sum|z_k|^2/2)^{1/2} >= sum|z_k|/sqrt(2K) (Parseval on Z_p: the characters w^{-+2kx}, k in {1..h}, are
  distinct; then Cauchy-Schwarz).
- **Oscillation floor.** A_osc(T) := min_z (max f - min f)/sum|z_k| >= max(A_s + A*, sqrt(2/K)). The first because f has mean
  0 (so max >= 0 >= min) and both max f and max(-f) are >= A* sum|z|. The second by the Bhatia-Davis inequality
  E f^2 <= (max f)(-min f) <= (osc/2)^2.
- **Flip-enlarged l2 depth, crude.** a(T) >= max(A_s/3, 1/sqrt(6K)). Averaging the plain and flipped test weightings over the
  other variable (or along the line a - b) isolates each single pattern two-sidedly, so H(z) >= max_T sup|f_T|.
- **Flip-enlarged l2 depth, ceiling.** a(T) <= A_s(T): single-pattern directions give exactly the two-sided depth.

**Correction for VERIFY.md** (entry "Vf.3 revisited"): the flip-enlarged depths quoted there for dense p = 11, 13 (0.386,
0.359) were search misses. Explicit single-pattern directions give a(dense) <= A_s = 0.332 (p = 11), 0.3005 (p = 13),
0.258 (p = 17) (`L6/t_enl_vs_As.py`, NUMERICAL but with explicit witness directions). **At p = 17 the dense set is below
0.272: single-offset flip aiming plus the proven eta-form cost side cannot certify it.**

## 4. The multi-offset lever, sharpened — PROVED + NUMERICAL

Writing psi_k = w^{k D/2} (D/2 taken mod p), s_k = Im psi_k (so cov_k(D) = 2 s_k^2), and translating the two weightings by
+-D/4, the lemma of section 2 becomes exact:
**nu_k = s_k * i * (v_k - u_k), with u, v ranging independently over the moment body M.** So the pair-offset reachable
set is i diag(s) (M - M), the *difference body*. The pair depth at offset D (relative to the clean weights) is the
inradius of M - M weighted by 2|s_k|. In particular a_D(T) >= A_osc(T) / (2 max_{k in T} |s_k|) >= A_osc/2, and
a_D >= A_s via the flip. The gain over the flip comes from frequencies with |s_k| < 1 (those covering D less than fully).
Numerics (`L6/t_pair.py`, `L6/t_osc.py`; single pattern; search = upper estimates):

| set | A_s (flip) | A_osc | pair depth a_D over all D |
|---|---|---|---|
| AP{1..8}, p = 59 | 0.320 | 0.633 | min 0.421 (D = 5); 0.42-0.48 at D >= 3; 0.68 at D = 2; 1.32 at D = 1 |
| dense p = 13 / 17 | 0.300 / 0.258 | 0.597 / 0.512 (~ the floor sqrt(2/K)) | (not run; A_osc/2 ~ A_s, so gains only from weights) |

So independent aims at +D and -D lift a progression from 0.32 to >= 0.42 at every offset. For Gauss-flat (dense) sets
A_osc ~ 2 A_s, and the lever gains only through the weights.
Still OPEN: the three-pattern version (weighted l2 inradius of B - B for the 2-D body, plus flips).

## 5. Direction-aware discount — a new sub-lemma (L6.5), partly PROVED

**Lemma (one clean pattern caps the discount) — PROVED.** If a population's junk vanishes on one pattern T
(J_T = sum_l c_l u_l = 0 with u_l = prod_{j in T} v_lj), then sum|c_l|^{2/3} >= 2^{1/3} |G|^{2/3}. So its discount is at most
sqrt(3/2) = 1.2247, however the junk is aimed.
*Proof.* The 2x2 matrix sum_l c_l (1, u_l)(1, u_l)^* has diagonal (G, G) and lower entry J_T = 0, so it is upper
triangular. Theorem 6.1 (feature cost) with n = 1 (nu = 2, chain vectors (1, u_l)) gives sum|c|^r >= 2^{1-r}|G|^r.
Check (`L6/t_onepattern.py`): 9000 random populations projected onto J_T = 0 (T = {1}, {2}, {1,2}):
min cost/(2^{1/3}|G|^{2/3}) = 1.0000, with equality at the two-atom pair.
**Consequence.** The full sqrt3 discount needs junk on all three patterns (the lone-atom shape J = c(v1, v2, v1 v2)). The
flattest (hardest to expose) junk is single-pattern, and that shape carries at most sqrt(3/2).
**Measured** (`L6/prod_dir.py`, flip-enlarged support function restricted to lone-atom directions, upper estimates):

| set | single-pattern depth A_s | lone-atom-direction depth |
|---|---|---|
| dense p = 59 | 0.140 | 0.383 |
| AP{1..8}, p = 59 | 0.320 | 0.568 |

The lone-atom shape at depth 0.38 has discount sqrt3 (1 - sqrt3 x 0.383) = 0.58 < 1: fully priced.

## 7. Verdict, and the sharpest statement that would close L6

**Does the gap contain a competitive set with delta(a(T)) > delta_crit(T, eps)?** (NUMERICAL, p = 59, 113, 211)
- **Single-offset accounting, optimistic depth (a = A_s).** Only the dense set at p = 59 with a tiny floor (eps = 0.005)
  breaks it (ratio 1.070). Every other set has A_s >= 0.244, so delta = 1.
- **Single-offset accounting, proven depth (a = c_lo).** It breaks on progressions of length 8 (eps <= 0.02, up to 1.10)
  and on the dense set (eps <= 0.01, up to 1.29). It also leaves the p = 211 optimal support uncertified by the proven
  0.272 step (c_lo = 0.251; fine only on the conjectural lone-atom curve).
- **With either lever, nothing exceeds 1.** Pair-offset (difference-body) aiming lifts the progression to >= 0.42 at every
  offset (single-pattern), so delta = 1. On the dense set, the direction-aware cap plus single-pattern exposure gives
  delta ~1.05 (ratio 0.86 at eps = 0.005); the lone-atom shape is fully priced (depth 0.38). The un-exposed cap sqrt(3/2)
  alone still gives 1.032 at eps = 0.005. So the dense tiny-floor case needs *both* the cap and some exposure of
  single-pattern junk.
- **Not a counterexample route.** Every "danger" above is a failure of the accounting, not of the theorem. Actual junky
  networks on the dense support at p = 59 reach at most 0.14 (one atom per frequency) and 0.52 (two atoms) of the
  ansatz (claude0923/NOTES sec 6, ptrend.py); unrestricted searches up to p = 31 never exceed 1. I did not find any
  set / junk configuration whose actual score approaches the block.
- **Adversarial size-10 search** (`L6/adversary.py`, minimising A_s subject to Gamma_T >= Gamma*/sqrt3, p = 59): best set
  {1,2,5,8,13,15,16,18,19,28}: Gamma_T = 0.300 (competitive), A* = 0.199, A_s = 0.299, c_lo = 0.186, E = 0.40.
  - The adversary could not push A_s below ~0.30 while staying competitive, so the optimistic accounting has delta = 1.
  - At the proven depth c_lo (delta = 1.174) it pays: ratio **1.089 at eps = 0.01 and 1.040 at eps = 0.03**
    (`L6/t_critical3.py`). This is the clearest case where the proven transfer is the bottleneck, not the truth.
  - The p = 113 adversary did not finish under machine load and was stopped.

**Sharpest statement that would close L6 (proposal).** Make the cost side shape-aware and the aim offset-aware:

> **(SG) Shape-graded exposure.** For every heavy junky set T (shares >= eps), every junk shape sigma, and the pair-offset
> (difference-body, with flips) depth a_sigma(T) restricted to shape-sigma directions:
> delta_sigma(a_sigma(T)) <= delta_crit(T, eps).

It splits into:
1. **Shape caps — PROVED at the extremes.** One clean pattern => discount <= sqrt(3/2) (section 5). Full sqrt3 => the
   lone-atom shape. OPEN: the interpolation delta_sigma(a) for mixed shapes (the analogue of CHAIN d.3's lone-atom curve,
   now shape by shape; computable by the fable0923 certificate machinery).
2. **Shape-restricted depths.** Lone-atom directions are ~2.7x deeper than single-pattern ones in every case measured
   (0.38 vs 0.14 dense p = 59; 0.57 vs 0.32 AP8). OPEN: a proof. Likely route: the product phases (v1, v2, v1 v2) couple the
   three patterns, so any row that hides pattern 1 exposes pattern {1,2}. That is a three-pattern analogue of the
   oscillation floor.
3. **Difference-body depth — PROVED reduction (section 4)**, three-pattern version OPEN: weighted l2 inradius of B - B.
4. **Floor waste — NUMERICAL only** (`floor_opt.py`): needed only for single-pattern junk (cap <= 1.2247) on large flat sets
   at tiny floors.

**Proof attempt status.** Everything labelled PROVED above is fully written out: the universal floors, the
difference-body identity, and the one-clean-pattern cap. The combination (SG) is not proved: pieces 1-3 each need one more
lemma, and piece 4 is a programme inequality with no analytic handle yet. The scan suggests (SG) holds with room at
eps >= 0.01. The only tight spot found is the dense set at eps = 0.005 (p = 59), and there the actual networks are far
below the block.
