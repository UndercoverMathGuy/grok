# L5: does a coverage defect make a network lose?

Fork report, 2026-09-25. Scope: single-frequency neurons, n = 2 operands, q = 2 (plain weight decay).
Scripts in `L5/`, run from `chain/L5/` with `uv run --with numpy [--with scipy] python <script>`.

**Short answer.**
- The whole-heavy-set version is PROVED, with explicit thresholds. But it is exactly the contrapositive of L1, so it
  adds nothing new.
- The version the chain actually needs — a *structured subset* of the heavy set covers badly — is FALSE in the
  per-frequency discounted accounting. PROVED for every p: any discount at all on any single frequency pays.
- What survives is quantitative: when every frequency of a structured set is forced to carry a share floor, the set
  tolerates a limited discount. This lowers the aim depth it needs, from 0.244 to roughly 0.12-0.20 (NUMERICAL).

## Symbols (plain reading with each)

| symbol | meaning |
|---|---|
| beta_k | budget share of frequency k: sum over neurons at k of squared weight norm, divided by total cost P; sum beta = 1 |
| cov_k(D) = 1 - cos(2 pi k D/p) | how well frequency k separates the right answer from the one D steps away |
| V_s(beta) = min_D sum_k beta_k^{3/2} cov_k(D) | own-share value: the score the shares could reach if every frequency got the full junk discount |
| B = 2(6p)^{-3/2} | normalising constant |
| Gamma* | best clean value (the programme); the block scores gamma_sym = B Gamma*/sqrt3 |
| heavy H / light L | frequencies with beta_k >= eps / < eps; sigma_L = total light share |
| discount delta on a frequency | factor by which its clean amplitude per cost^{3/2} beats the block: delta = 1 is block rate; delta = sqrt3 is the full discount (one atom, junk hidden for free) |
| Gamma_c | weighted programme: max min_D sum y_k cov_k(D) s.t. sum_k c_k y_k^{2/3} <= 1; c_k = 3^{1/3} delta_k^{-2/3} (block: c = 3^{1/3}; full discount: c = 1) |

## 1. Whole-heavy-set lemma — PROVED

**Own-share bound** (claude0923/NOTES sec 8; re-derived here for single-frequency nets). For a neuron at frequency k,
(B) gives |c_ik| <= (p/6)^{3/2} |theta_i|^3, so |G_k| <= (p/6)^{3/2} sum_{i at k} |theta_i|^3 <= (p/6)^{3/2} (beta_k P)^{3/2}.
Lemma 2 then gives margin <= (2/p^3) min_D sum_k cov_k(D) |G_k|, hence **gamma <= B V_s(beta)**.

**Lemma L5-whole.** If at some offset D0 the heavy part covers poorly, sum_{k in H} beta_k^{3/2} cov_k(D0) <= delta, then
gamma <= B (delta + 2 sqrt(eps) sigma_L). So the network scores strictly below gamma_sym whenever
**delta + 2 sqrt(eps) sigma_L < Gamma*/sqrt3**.
*Proof.* V_s(beta) <= sum_k beta_k^{3/2} cov_k(D0) = (heavy part at D0) + (light part at D0). The light part is
<= 2 sum_L beta_k^{3/2} <= 2 sqrt(eps) sigma_L, because beta^{3/2} <= sqrt(eps) beta when beta < eps. Then apply the
own-share bound. No aiming and no L2 hypothesis are needed: the own-share bound already gives every frequency at most
the full sqrt3 discount. []

**Numerical check** (`ownshare_check.py`): 440 positive-margin block + junk nets at p = 7, 11, 13.
max gamma/(B V_s) = 0.573 (<= 1; blocks sit at 1/sqrt3). The split bound is never violated (max excess 1e-16).

With L0 (Gamma* >= 1/(4 sqrt(2 ln h))), for every p: loses if delta + 2 sqrt(eps) < 1/(4 sqrt(6 ln h)).
**Converse (sharpness).** At eps = 0 the threshold Gamma*/sqrt3 is exact for this accounting: V_s is by definition the
minimum over offsets. The accounting itself is only reached if junk could be hidden for free, which real networks cannot do.

**Why this adds nothing.** L1 says a competitive network's heavy part covers *every* offset at level
>= Gamma*/sqrt3 - 2 sqrt(eps). L5-whole says a whole-heavy-set defect loses. These are the same statement. In a competitive
network, whole-heavy-set defects simply do not occur.

## 2. Zero-slack lemma — PROVED (all p): partial defects cannot work frequency by frequency

**Lemma Z.** For every odd prime p, every frequency k and every delta > 1: giving k alone the discount delta (all
other frequencies at block rate) makes the weighted programme exceed Gamma*/sqrt3.
*Proof.* (i) Dilation. For lambda in Z_p^*, the map k -> +-lambda k permutes {1..h} and permutes the offsets, so it
preserves the programme. Take any optimal support S* and any k0 in it. With lambda = k k0^{-1}, the image of S* is an
optimal support containing k. (ii) Take the optimal y* on that support, which has y*_k > 0 and uses the full block
budget 3^{1/3} sum y^{2/3} = 1. With the discount on k, the same y* uses budget 1 - 3^{1/3}(1 - delta^{-2/3}) y*_k^{2/3} < 1.
Scale y* up by t > 1 to fill the budget: the value becomes t Gamma*/sqrt3 > Gamma*/sqrt3. []
**Reading.** The per-frequency programme accounting has no slack anywhere. The adversary can always route an optimal
spectrum through any frequency that gets even a tiny unpriced discount. So "this structured set covers some offset
badly" cannot, by itself, rule out junk on that set.

**Numerical confirmation** (`partial_defect.py`, `crit_discount.py`, exact vertex enumeration):
- Every set of size 1-3 at p = 13, 17, 19, 23 (493 sets) has critical discount exactly 1: every discount pays.
- With the full discount, even strongly defective progressions pay. At p = 23, {1,2} (min mean coverage 0.09) reaches
  1.25x the block; {1,2,3} reaches 1.35x. The optimiser puts 43-64% of the budget on them and patches the bad offsets
  with other frequencies. Larger sets reach sqrt3 = 1.732x.

## 3. What survives: forced participation (share floors) — NUMERICAL

In the real chain, a heavy junky set T has *every* frequency at share >= eps (otherwise it is light, handled by L2).
Forcing every frequency of a structured T to carry budget wastes some of it at T's bad offsets. So T can absorb a
limited discount. `floor_test.py` and `floor_crit.py` (SLSQP multistart; values are lower bounds, so the critical
discounts below are over-estimates):

| p | T | floor eps | ratio at full discount | delta_crit | depth needed on T (lone-atom curve delta = sqrt3(1 - sqrt3 a)) |
|---|---|---|---|---|---|
| 23 | {1..5} | .03 / .06 | 1.43 / 1.40 | 1.16 / 1.14 | 0.191 / 0.198 |
| 23 | {1..8} | .03 / .06 | 1.53 / 1.50 | 1.12 / 1.16 | 0.203 / 0.192 |
| 59 | {1..5} | .03 / .06 | 1.23 / 1.23 | 1.26 / 1.25 | 0.158 / 0.159 |
| 59 | {1..8} | .03 / .06 | 1.23 / 1.19 | 1.29 / 1.38 | 0.149 / 0.118 |

Full-discount junk on a progression still pays (1.19-1.53) even with every progression frequency forced to 3-6% share.
Only partial discounts are tolerated. So the defect buys slack in the **depth requirement** (0.244 -> ~0.12-0.20 on
these sets). It does not let us skip aiming.

## 4. Consequences for the chain

1. **L5 as written in CHAIN.md is proved but empty** (it is L1). The interface "L4 gives a defect -> L5 says it loses"
   does not work: L4 can only give defects for a structured *subset*, and Lemma Z shows subset defects never suffice
   unpriced.
2. **Correct replacement for L4 + L5.** For a heavy junky set T (every share >= eps), show that the discount
   delta(a(T)) available at T's aim depth a(T) is at most delta_crit(T, eps), the critical discount of the
   share-floored programme. Structure then helps twice: it lowers a(T), but it also raises delta_crit(T, eps).
   On progressions, delta_crit ~ 1.12-1.38.
3. **Only in this accounting.** Everything above treats hidden junk as free apart from the depth-graded discount.
   A stronger lever, outside this fork's scope and not tested here: the same junk must hide at *every* near-binding
   offset at once, and the coverage weights cov_k(D) differ across those offsets.
