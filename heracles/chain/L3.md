# L3: almost-dissociate frequency sets can be aimed at

Fork report, 2026-09-25. Scripts in `chain/L3/`. Run with `uv run --with numpy [--with scipy] python <script>`.
Labels: PROVED (full proof here), CERTIFIED (exact integer/rational computation, script named), NUMERICAL, FALSE.

## 0. Words

- **p**: odd prime. **H**: a set of K frequencies in {1, ..., (p-1)/2}. **m_k = 2k mod p**: the *doubled frequency* of k.
  Junk of frequency k lives on the row mode 2k, so all aiming happens at the modes m_k.
- **pattern eps**: a vector in {-1, 0, 1}^H; its **sum** is s(eps) = sum_k eps_k m_k mod p. Its **support** |eps| is the
  number of nonzero entries. e_k is the pattern with a single +1 at k.
- **relation**: a nonzero pattern with sum 0. **representation of m_k**: a pattern with sum m_k, other than e_k itself.
- **strongly dissociate** set B: the 3^{|B|} sums s(eps), eps in {-1,0,1}^B, are all distinct (VERIFY.md V3a.8a:
  this, not "no relation", is what Riesz products need).
- **one-sided depth A\*(H)**: the largest A such that every target vector (t_k) with |t_k| <= A is the vector of averages
  E_w[w^{m_k x}] for some probability weighting w of Z_p. Dual form: A*(H) = min over z != 0 of max_x Re sum z_k w^{m_k x} / sum|z_k|.
- **two-sided depth A_s(H)**: the same with the hull of the moment body and its negative (the flip lemma, VERIFY.md
  Vf.1, supplies the negative). Dual form: max_x |Re sum z_k w^{m_k x}| in place of max_x Re(...).
- **polyball depth**: what the chain needs. The flip-enlarged three-pattern aim body must contain the l2-ball of
  radius 0.272 (proven cost side, V3b). From (A*, A_s) it is obtained by a transfer lemma:
  - fable0923 Lemma 2 (exact): A(2+A)/3 with A = min(A*, 0.47); needs A* >= 0.3476;
  - the flip-enhanced transfer (VERIFY.md "New lemma"): c(A*, A_s), constant computed on a sphere grid (NUMERICAL).
- **error sums**, for 0 < rho <= 1/2:
  - E_0(rho) = sum over relations eps of rho^{|eps|} (mass errors);
  - E_k(rho) = sum over representations eps of m_k of rho^{|eps|} (moment errors at k);
  - superscripts even / odd restrict to patterns of even / odd support.

## 1. Lemma L3-A (Riesz product with relation errors) — PROVED

For every set H and every rho in (0, 1/2]:

    A*(H) >= min_k (rho - E_k(rho)) / (1 + E_0(rho)),
    A_s(H) >= min_k (rho - E_k^odd(rho)) / (1 + E_0^even(rho)).

**Proof.** Given a dual direction z, put lambda_k = rho conj(z_k)/|z_k| and
R(x) = prod_{k in H} (1 + lambda_k w^{-m_k x} + conj(lambda_k) w^{m_k x}).
Each factor is 1 + 2 rho cos(.) >= 0, so R >= 0. R has at most K < p zeros, so its mean M is > 0. Expanding the product
gives one term per pattern eps, with coefficient prod_k c_k(eps_k) (c(+1) = lambda_k, c(-1) = conj lambda_k, c(0) = 1)
and frequency s(eps). Averaging over x in Z_p keeps exactly the patterns with sum 0:
M = 1 + sum_{relations} prod c, so |M - 1| <= E_0(rho). By the same count, the weighting w = R/(pM) has
E_w[w^{m_k x}] = (lambda_k + err_k)/M, with err_k = sum over representations of m_k of prod c, so |err_k| <= E_k(rho).
Hence Re sum_k z_k E_w[w^{m_k x}] >= (rho sum|z_k| - sum|z_k| E_k)/M >= min_k(rho - E_k) sum|z_k| / (1 + E_0)
when the numerator is positive. Since max_x >= E_w, this proves the one-sided bound.

*Two-sided.* Also build R' from -lambda and take the flipped vector -E_{w'}[.], a point of minus the moment body.
Mix it with the first vector using weights M/(M+M') and M'/(M+M'); the mix lies in the symmetric hull. Negating lambda
multiplies each pattern's coefficient by (-1)^{|eps|}. So the mix equals (lambda_k + err_k^odd)/(1 + mass^even), where
err^odd keeps the representations of odd support and mass^even keeps the relations of even support (numerator M mu + M' (-mu') = 2 lambda_k + (err_k(lambda) - err_k(-lambda)) = 2 lambda_k + 2 err_k^odd;
denominator M + M' = 2 + 2 mass^even). The same estimate follows. QED.

**Reading.** A Riesz product aims perfectly at every frequency. Relations among the doubled frequencies leak a small
amount of aim, rho^{support} per relation. The flip cancels every relation of odd support in the mass and every
representation of even support in the moments. In particular one **Schur triple a + b = c is invisible to the two-sided
depth**: its mass relation has support 3 and its moment representations have support 2.

**Checks** (`sanity.py`): the densities are built explicitly for 300 random targets on 4 sets at p = 1009 and 10007.
R >= 0 always. The achieved value is >= the bound, and the true max is >= the achieved value (slacks >= -2e-14,
i.e. rounding). The error counts are exact integer histograms (`riesz_bound.py`, enumeration of all 3^K patterns), and
the bound is evaluated in exact rational arithmetic at rational rho: every numerical bound below is **CERTIFIED**
for the stated set.

## 2. Corollary L3-B (the almost-dissociate form) — PROVED

Let H = B u C with B strongly dissociate and |C| = r. Then **there are at most 3^r - 1 relations, and at most
3^r - 1 representations of each m_k**. (For each choice of the C-part of a pattern, strong dissociativity leaves at most
one B-part; the C-part 0 gives only the trivial pattern, resp. e_k.)
If moreover every relation has support >= j + 1 and every representation has support >= j, then, with R = 3^r - 1:

    A*(H) >= max_rho (rho - R rho^j) / (1 + R rho^{j+1}).

(Two-sided: count only representations of odd support and relations of even support.)

Smallest j with A* >= 0.3476, which is enough for polyball 0.272 via the exact fable transfer (`tables.py`):

| r = |H \ B| | A* bound at j = 3 / 4 / 5 / 6 / 7 / 8 / 9 | j needed |
|---|---|---|
| 1 | 0.259 / 0.356 / 0.424 / 0.462 / 0.481 / 0.490 / 0.495 | **4** |
| 2 | 0.134 / 0.231 / 0.309 / 0.373 / 0.425 / 0.462 / 0.481 | **6** |
| 3 | 0.075 / 0.158 / 0.233 / 0.297 / 0.352 / 0.399 / 0.439 | **7** |
| 4 | 0.043 / 0.109 / 0.177 / 0.239 / 0.294 / 0.341 / 0.383 | **9** |

The r = 1 case is exact. If 2c is a signed sum of j elements of 2B, the patterns are: 2 relations of support j + 1;
at most one representation of support j for each k in that sum and for c; two of support j + 2 for every other k. So

    A*(B u {c}) >= max_rho (rho - max(rho^j, 2 rho^{j+2})) / (1 + 2 rho^{j+1}),

and the two-sided bound is exactly 1/2 when j is even (every pattern then has the parity the flip cancels).

Checked on constructed sets at p = 100003 (`corollary_check.py`; |B| = 7, j = 2..6): the exact-count bound equals the
formula to 4 digits (0.2128, 0.3340, 0.4118, 0.4545, 0.4769), and the two-sided bound is 0.5000 for every even j.
Polyball depth for r = 1 (`transfer_eval.py`):
- j = 2 (a Schur triple): (A*, A_s) = (0.213, 0.500) gives flip-transfer 0.2731, just above 0.272 (NUMERICAL constant,
  borderline, needs the exact transfer certificate);
- j = 3: (0.334, 0.334) gives 0.260, **short**;
- j >= 4: (0.412, 0.500) gives 0.371, passes.

## 3. Random sets — PROVED (asymptotic) and CERTIFIED / NUMERICAL (actual sets)

**Lemma L3-C (expected errors) — PROVED.** Let H be a uniformly random K-subset of {1..h}, h = (p-1)/2. Fix a pattern
eps. Condition on every element except one element i in its support (not k, for a moment pattern). That element is
uniform over at least h - K + 1 values, and x -> eps_i 2x is injective on {1..h}, so the pattern sum hits the required
residue with probability <= 1/(h - K + 1). Patterns of support 1 never count (2k != 0, and distinct elements have
distinct +-2k). Hence

    E[E_0(rho)], E[E_k(rho)] <= Q(rho) := ((1+2rho)^K - 1 - 2K rho) / (h - K + 1),

and similarly with the odd/even parts for the two-sided errors. By Markov applied to the sum of the K + 1 errors,
with probability >= 1 - delta every error is <= (K+1) Q / delta. Put that into L3-A.

Consequence: for K = c ln p with c < 1/ln 2 = 1.44, choosing rho < 1/2 with c ln(1 + 2rho) < 1 makes the errors
-> 0 as p grows. So A*(H) -> 1/2 in probability, and random sets of every competitive size are eventually aimable.
The guaranteed rate is slow (`tables.py`, delta = 1/2):

| c | ln p where one-sided A* >= 0.3476 (guaranteed w.p. >= 1/2) |
|---|---|
| 1.0 | 18.8 (p ~ 1.5e8) |
| 1.3 | 33.1 (p ~ 2e14) |
| 1.44 | 47.7 (p ~ 5e20) |

The Markov factor (K + 1)/delta is the lossy part.

## 5. Summary

- **PROVED**: L3-A. Aim depth >= (rho - E_k)/(1 + E_0), with the E's weighted counts of signed relations among the
  doubled frequencies; the two-sided version sees only even-support relations and odd-support representations.
  L3-B: with B strongly dissociate and r extra elements, R = 3^r - 1. L3-C: random sets of size c ln p, c < 1.44,
  are aimable for p large enough, with explicit but huge thresholds.
- **Where it crosses the chain's requirement** (polyball 0.272 <=> A* >= 0.3476 through the exact transfer):
  - r = 1: j >= 4, or j = 2 through the two-sided depth plus the flip transfer (borderline 0.273);
  - r = 2: j >= 6; r = 3: j >= 7; r = 4: j >= 9.
  - Random K = ln p sets: typically at p >= 10^4.
  - Random K = 1.3 ln p sets (the K* scale): not at p <= 10^5 by this lemma; the p = 10^5 median polyball is 0.258.
- **The gap**. At the competitive size, random sets have about 3^K/p ~ p^{0.43} relations, and the triangle inequality
  on their errors is what loses. Truth (section 4) is higher. Closing it needs cancellation among the error terms (second
  moment over random sets; for fixed sets, a better density than one Riesz product, e.g. optimising rho per coordinate)
  or a better transfer than from 1-D depths.
- Tried and marginal (NUMERICAL, `perrho.py`): a separate rho per frequency (same proof) moves the p = 1009, K = 9
  medians from 0.216 / 0.274 to 0.212 / 0.283 (one- / two-sided, different draws). The loss is the triangle inequality,
  not the choice of rho.

## 6. Interface for L2: the aim's moments at junk modes OUTSIDE H — PROVED + CERTIFIED per set

**Lemma L3-D — PROVED.** For the full-H Riesz aim of L3-A (Riesz on B u C with its relation corrections) and every
residue u not in {0} u {+-2k : k in H} (i.e. the doubled frequency of any frequency outside H):

    |E_w[w^{u x}]| <= tau_1 := max_u F(u) / (1 - E_0),          F(u) = sum over patterns eps with s(eps) = u of rho^{|eps|}.

For the two-sided (flip-mixed) aim, the mixed vector's coefficient at u is (F_lambda(u) - F_{-lambda}(u))/(M + M'), and
only odd-support patterns survive:

    |.| <= tau_2 := max_u F_odd(u) / (1 - E_0^even).

Proof: the same expansion as L3-A, now read off at the frequency u; |prod c| = rho^{|eps|} and M >= 1 - E_0 (resp.
(M + M')/2 >= 1 - E_0^even). Every u outside H is only reached by patterns of support >= 2 (support 1 gives exactly
+-2k, k in H). For **strongly dissociate H** each u carries at most one pattern, so

    tau_1 = rho^2 (= 1/4 at rho = 1/2, R = (1 + tau)^2 = 25/16),   tau_2 = rho^3 (= 1/8, R = 81/64 = 1.266).

With B strongly dissociate and |C| = r: at most 3^r patterns per u, so tau_1 <= 3^r rho^2 / (1 - E_0).

**Pairing caveat (important for the chain).** These leak bounds are for *per-slot Riesz aims*, i.e. product weightings
w1(a) w2(b). Those realise the product torus (t1, t2, t1 t2), so their cost-side partner is the product-torus
population inequality (DA: proved at depths (1/2, 1/2); VERIFY Vf.3 region measured, equal depth ~0.43). It is NOT the
eta-form 0.272, which needs l2-ball aims built by the transfer lemma (non-product, leak uncontrolled, R = 4 per L2).
Per-slot depths vs the Vf.3 region (flipped slot two-sided, other slot one-sided; NUMERICAL region):
- strongly dissociate (0.5, 0.5): OK.
- B + 1, j = 4 (0.5, 0.41): OK (needs 0.447).
- random K = 9, p = 1e4 (0.48, 0.48): OK.
- B + 1, j = 2 (0.5, 0.2): FAIL.
- B + 1, j = 3 (0.33, 0.33): FAIL.
- random K = 12, p = 1e4 (0.30, 0.26): FAIL.
- random K = 15, p = 1e5 (0.38, 0.30): FAIL.

So at the competitive size K ~ 1.3 ln p and p <= 1e5, low-leak aims are not yet deep enough for the proven
product-torus cost side. Closing this needs either the product-torus region certified below 1/2, or a low-leak
l2-ball aim (a transfer lemma built from Riesz pieces, whose leak can be tracked the same way).
