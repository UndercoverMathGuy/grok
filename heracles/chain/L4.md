# L4: structure gives a coverage defect — and the race that actually matters

Fork report, 2026-09-25. n = 2 operands, q = 2. Scripts in `chain/L4/` (`uv run --with numpy --with scipy python <script>`).
Labels: PROVED (full proof here), NUMERICAL (evidence only), FALSE (counterexample given).

## 0. Symbols

| symbol | meaning in words |
|---|---|
| p, h = (p-1)/2 | odd prime; number of positive frequencies |
| H, T | a set of frequencies (sign of a frequency is irrelevant) |
| \|\|x\|\|_p | distance from x/p to the nearest integer, in [0, 1/2] |
| cov_k(D) = 1 - cos(2 pi k D / p) | how well frequency k separates answers D apart (0 = not at all, 2 = best) |
| coverage defect of H at D | sum_{k in H} w_k cov_k(D) / sum w_k for weights w >= 0; typical value ~1, small = H barely covers offset D |
| one-sided depth A*(H) | min over coefficient vectors z != 0 of max_y Re sum_k z_k e(-2ky/p) / sum \|z_k\|: how deep one weighting can aim at H's junk from one side |
| two-sided depth A_s(H) | same with \|Re ...\| (sup norm): the depth after the flip; = 1 / (Sidon constant of 2H) |
| relation of H | an integer vector m with sum_k m_k k = 0 mod p; short if max \|m_k\| is small |
| delta_crit(T, eps), a_req | L5's critical discount of the share-floored programme and the aim depth it requires, a_req = (1 - delta_crit/sqrt3)/sqrt3 (lone-atom curve) |

## 1. Structure gives a coverage defect (all PROVED)

**Lemma A (coverage vs approximation).** cov_k(D) = 2 sin^2(pi \|\|kD\|\|_p), so 8 \|\|kD\|\|_p^2 <= cov_k(D) <= 2 pi^2 \|\|kD\|\|_p^2.
*Proof.* 1 - cos 2x = 2 sin^2 x, and 2x/pi <= sin x <= x on [0, pi/2].

**Lemma B (progressions).** If H is contained in {+-j s : 1 <= j <= L} with s != 0, then at D = s^{-1} (mod p) every k = +-js has
\|\|kD\|\|_p = j/p, so sum_{k in H} w_k cov_k(D) <= 2 pi^2 (L/p)^2 sum w_k. Averaged over the full progression the defect is
(pi^2/3)(L+1)(2L+1)/p^2 exactly up to the sin <= x step.
*Numerics* (`L4/t1_structured.py`): exact at p = 1009, 10007, 100003 for L = 4, 8, 16; D = s^{-1} is the global minimiser.

**Lemma C (box Dirichlet; generalised progressions).** Let g_1..g_d be residues and Q_1..Q_d positive integers with
Q_1 ... Q_d < p. Then some D != 0 has \|\|g_i D\|\|_p < 1/Q_i for every i. Consequently, if every k in H has a representation
k = sum_i n_i g_i with \|n_i\| <= N_i, then \|\|kD\|\|_p < rho := sum_i N_i/Q_i for every k in H, and
sum_{k in H} w_k cov_k(D) <= 2 sin^2(pi min(rho, 1/2)) sum w_k, and the sharper average
sum w_k cov_k(D) <= 2 pi^2 sum_k w_k (sum_i \|n_i(k)\|/Q_i)^2.
*Proof.* Split the torus [0,1)^d into Q_1...Q_d boxes of sides 1/Q_i. The p points (q g_i / p mod 1)_i, q = 0..p-1, outnumber
the boxes, so two, q1 != q2, share a box; D = q1 - q2 is non-zero mod p and each \|\|g_i D\|\|_p < 1/Q_i. Then use the
triangle inequality and Lemma A. Choosing Q_i proportional to N_i gives rho ~ d (N_1...N_d/(p-1))^{1/d}: a defect whenever the
progression's "volume" N_1...N_d is well below p/(4d)^d.
*Numerics* (`t1_structured.py`): the bound held in all 12 GAP cases (d = 2, 3, 4; p = 10^4 to 10^6); the observed
defects are far below the bound (e.g. 4x4 GAP at p = 100003: max cov at D 0.003 vs bound 0.013).

**Lemma D (small dissociated dimension).** Let B be a maximal subset of H with no non-trivial {-1,0,1}-relation, d = |B|.
Every k in H \ B is then a signed sum of elements of B (adding k to B creates a relation that must involve k). So Lemma C
applies with N_i = 1 and Q = floor((p-1)^{1/d}) (so Q^d < p): \|\|kD\|\|_p < j(k)/Q, j(k) = number of generators used.
*Reading.* Useful only while Q >~ 4 j_max, i.e. d <~ ln p / ln(4 j_max). A generic set of size K has d ~ min(K, log_3 p), so
Dirichlet only gives \|\|kD\|\| ~ p^{-1/K}. At K ~ 1.3 ln p that is e^{-1/1.3} ~ 0.46: no defect at all.
*Numerics* (`t1_structured.py`): cubes d = 3..6 at p = 10007 and 10^6 obey the bound. At p = 10007 the bound is already
near-vacuous from d = 5.

## 2. The depth side

**Lemma F (Fejer-product aiming; PROVED).** If H has no non-zero relation m with max_k \|m_k\| <= N + 1, then for any phases
theta_k the density w(y) = p^{-1} prod_{k in H} F_N(2ky/p - theta_k/(2 pi)) (F_N the Fejer kernel of order N, which is >= 0)
has mass 1 and has average of e(2ky/p) equal to (N/(N+1)) e^{i theta_k} exactly. So A*(H) >= N/(N+1).
*Proof.* Expand the product: the term indexed by (n_k), \|n_k\| <= N, sits at frequency sum n_k (2k) with coefficient
prod F^_N(n_k) e^{...}. Mass: only n = 0 lands on 0 (a non-zero n landing on 0 is a relation with max \|n_k\| <= N).
Moment at 2k: n lands on 2k iff n - e_k is a relation, with max \|.\| <= N + 1, so only n = e_k does. F^_N(1) = N/(N+1).
N = 1 is the Riesz product of V3a.8a (distinct signed sums = no relation with coefficients in {-2..2}).
*Contrapositive.* **Depth below 1/2 forces a short relation** (coefficients in {-2..2}). That is the only unconditional
"low depth => structure" statement here. One short relation alone costs little depth: {k1, k2, k1 + k2} + 5 random
has two-sided depth ~0.60 at p = 1009.

**Lemma G (progressions; PROVED).** For H = {s, 2s, ..., Ls}:
- one-sided depth <= 1/L: take z_j = -2(1 - j/(L+1)); then Re sum z_j e(...) = 1 - F_L(.) <= 1, while sum \|z_j\| = L;
- two-sided depth >= 1/sqrt(2L) (sup norm >= l2 norm; Parseval over distinct characters, sum\|z\|^2 >= (sum\|z\|)^2 / L);
- two-sided depth <= sqrt(2/L') <= 2/sqrt(L), where L' <= L is the largest power of 2 (Rudin-Shapiro polynomial on a
  sub-progression: \|P\|^2 + \|Q\|^2 = 2L' on the circle; depth is monotone under taking supersets).
So progressions have one-sided depth ~1/L (Dirichlet-type hiding) but two-sided depth ~1/sqrt(L).

**Observation H ("low depth => global coverage defect" is false as a global statement; PROVED).** Depth can only drop when
frequencies are added (a minimum over more directions), while the coverage defect of H plus R is at least the share of R times
R's own defect. So a progression plus enough unstructured frequencies has depth <= 2/sqrt(L) and no global defect.
*Numerics* (`t2_depth_vs_defect.py`, `t2b.py`, p = 1009, search = upper estimates of depth):

## 3. The race (coordinator's pivot): achievable depth vs depth required under a share floor

**Two ceilings on what aiming can ever deliver (PROVED).**
- *True flip-enlarged l2-ball depth <= A_s(T).* Take a direction supported on one junk pattern (say {1}). The three
  aim variants give max f, max(-f), max f, so the support function is the sup norm of f. The ratio is then the two-sided
  K-mode ratio.
- *Transfer-certifiable depth c(A*, A_s) <= A_s.* Evaluate at the direction supported on the a+b pattern. The six
  elimination orders give per-frequency values A_s, A* A_s, A_s, A* A_s, A*, A*, all <= A_s. Any weighted average
  is <= A_s. (Numerically c <= 0.817 A_s on a grid, `L4/t5b.py`.)
- With Lemma G: **on a progression of length L, any single-offset flipped aim reaches depth <= 2/sqrt(L), and the
  transfer certifies <= 2/sqrt(L).** On a d-dimensional GAP of size K the same holds with tensor Rudin-Shapiro:
  two-sided depth <= prod_i sqrt(2/L_i) = 2^{d/2}/sqrt(K).

**Consequence (PROVED, given the lone-atom discount curve delta(a) = sqrt3 (1 - sqrt3 a)).** On a progression T of length
L carrying junk with share floor eps, the chain as built closes on T only if
delta_crit(T, eps) >= sqrt3 (1 - sqrt3 * 2/sqrt(L)) = sqrt3 - 6/sqrt(L),
i.e. **the critical discount of long progressions must approach full discount sqrt3 at rate ~1/sqrt(L).** That is a
statement about the share programme alone, with no aiming in it. It can be tested numerically, and it is the precise
form the large-p additive combinatorics takes for progressions.

proved only at the endpoints.

- The required depth falls faster than the achievable depth as the progression grows. At p = 113, a_req goes
  0.12 -> 0.04 from L = 4 to 16, while achievable goes ~0.13 -> 0.09 (searched A_s). The critical discount approaches

## 4. Summary for the chain

1. PROVED: structure => coverage defect (Lemmas A-D, explicit). Low depth => a short relation (Lemma F, contrapositive
   of Fejer aiming). Progressions: one-sided depth <= 1/L, two-sided in [1/sqrt(2L), 2/sqrt(L)] (Lemma G). Any flipped
   single-offset aim, and the transfer, give <= A_s <= 2/sqrt(L) on a progression.
2. FALSE as a route: "low depth => global coverage defect" (Observation H; supersets). And by the L5 zero-slack
   lemma, defects alone never make junk lose.
3. The large-p statement for progressions reduces exactly to a share-programme statement: delta_crit(AP_L, eps) >=
   sqrt3 - 6/sqrt(L) (with the lone-atom curve). NUMERICAL evidence at p = 113 that it holds with room for L = 4..16;
   not proved for any family of p.
4. Main open items: (i) certified two-sided depth lower bounds better than the Parseval floor on progressions / GAPs
   (grid-LP certificates get ~0.35 at L = 5 vs the floor 0.32); (ii) a proof that delta_crit of progressions tends to sqrt3
   as the forced share grows, with a rate; (iii) the same for 2-D GAPs; (iv) the lone-atom discount curve below 0.272.
