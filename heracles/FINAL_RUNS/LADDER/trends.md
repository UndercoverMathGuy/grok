# Part 2 — trends from free training (gated chain, `--act prod`)

Recipe: penalty off until train CE < 0.8 ln p, then the stated lambda; constant lr; grad-norm clip 1; init 4 (n = 2) / 14 (n >= 3); width m = 500 (the constructed K*-net needs `(n+1)K` <= 30 neurons, so every run has ~20x the width it needs).

`quality` = the run's normalized margin as a fraction of the exact ceiling `mu N^-(nu-q)/q B Gamma_s(p)`; `junk` = 1 - clean fraction (the share of the logit-table energy that is not a function of D = sum a - c); `K_abl` = interface-ablation count; `K_d25` = number of frequencies whose removal costs >= 25% of the min-margin (this is the instrument that is EXACT on constructed nets, 4/4); `K_5pct` = Fourier-energy head count; `N_.05` = number of frequencies with >= 5% of the top amplitude — a TAIL statistic proportional to the number of frequencies present, not a count.
