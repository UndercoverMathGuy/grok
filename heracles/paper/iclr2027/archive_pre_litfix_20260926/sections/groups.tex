\section{Finite groups}\label{sec:groups}
% TODO: brief from s5theory/S5_THEORY.md §10. Skeleton only.

We conclude by studying group composition on finite groups $G$: the input space is $\curlyx:=G\times G$, the output space is $\curlyy:=G$, and given inputs $a,b\in G$ the network is trained to predict $c=ab$. The same argument as in Sections~\ref{sec:approach} and~\ref{sec:cyclic} applies, with frequencies replaced by irreducible representations. It gives an exact margin ceiling in which each irreducible representation pays a price set by how cheaply the matrix-multiplication tensor can be written as a sum of products; at even degree this is the schoolbook algorithm, with $d^\nu$ neurons per $d$-dimensional representation. Among networks without same-representation interference this ceiling is attained and fixes the number of features: one representation on $S_5$ and the Galois-conjugate pair on $A_5$, as observed. Unlike on cyclic groups of prime order, networks with structured interference can exceed the ceiling on some groups ($D_3$, $S_4$, $\sZ_{12}$), so there the count is exact only within the interference-free class.
